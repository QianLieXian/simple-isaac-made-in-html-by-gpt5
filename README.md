# 尘封地窖 · THE UNDERCROFT

一个单文件 Roguelite：游戏逻辑、CSS、Canvas 渲染、图标和声音全部内嵌于 `index.html`。无需构建、安装依赖或联网加载素材，下载后可在现代浏览器中直接打开，也可部署到 GitHub Pages 等静态站点。

## 画面与手感

- 斜视 2.5D 地面投影，默认 1.12 倍战术近景镜头，随角色平滑移动；可切换全景或全屏，画面内始终显示生命、资源与主动/卡牌状态。生物按碰撞半径统一躯干宽度，低矮石块在遮住角色时半透明，碰撞仍使用统一的地面坐标。
- 障碍改为 20 单位小砖，每组最多两块，组间预留 56 单位净空；陷阱避开墙边和砖群。生成时用角色宽度检查可达区域，清除封闭小口袋。
- 门框改为有开口的石拱门，以房间颜色、专属图标和门闩区分目的地与锁定状态；隐藏门保留裂缝线索。
- 十种凸四边形房间，包括横廊、纵厅、方室、梯形厅及偏斜石廊。墙、门、地图和 HUD 用一致的房型颜色区分用途。
- 缓起步、松键收速、沿墙滑动、弹丸方向击退和按体型推挤。人物无敌期间依然受物理推动；地面材质改变牵引力。
- 粗帧步态、攻击姿态、受击闪色、六阶段材质死亡与溅落；59 件道具各有外观变化；靴子、衣服、披风、背包、护肩、面具、额外眼睛和头饰按部位组合，拾取时举起遗物，射击时面部与手臂反馈。武器蓄力、冲刺轨迹和特殊攻击范围分别呈现。
- 遗物置于立体底座，掉落物有厚度、漂浮和闪光；火堆、粪堆与尖刺分别绘制，高亮危险轮廓。人物、敌人、跟随者、炸弹、掉落物与双方子弹都有落地阴影。
- 做旧石板、划痕、凹坑、土粒、尘埃、虫蚁、雨丝与浮光；纹理每房间缓存，视觉随机不消耗战斗随机序列；生物的待机、呼吸各有独立节奏。火光、脚底阴影与暗角统一氛围。
- 页面按钮、图鉴、装备栏、音量设置、触屏键盘、调试台和弹窗采用木石、羊皮纸与暗金的复古样式。
- 生物使用共享脚底锚点的体积身体、明暗面和独立附肢，外轮廓带一游戏像素的白描边；五官跟随各自头部，死亡延续同一身体。地面投影阴影标示实际占地；弹丸、尸体与物体按地面前后关系遮挡。方墙和遗物底座补齐侧面。
- 十类房型向外拓宽，砖群与掉落物缩小，减轻窄室拥堵。渲染提供「流畅 800×600 / 清晰 1600×1200 / 精细 2400×1800」三档，同时切换内嵌矢量图标缓存精度，设置本地保存；手机在设置中切换。
- 迷你地图使用独立界面层，背景 80% 透明，长条及大地图整体缩放并裁切到边框内；手机放在攻击区上方，避开按键。地图采用手记边框、房间实际四边形比例、房型图标和门路连线。当前房间突出，走过的房间亮，相邻待探索房间深灰且显示用途；逐步探路，不提前显示整层或未打开的密室。
- 相反射击键以最后按下的方向为准；快速换向即使发生在两次更新之间，也用于最终发射方向。短剑的视觉转向不再拖慢实际释放。蓄力跟班显示独立进度条并响应射速；转屏、暂停和失焦取消未发出的蓄力，触屏与实体按键独立持有输入。
- 跟班编队保留最多四名出战，额外获得的跟班进入候补，不再被无声删除。桌面和手机设置中均可入列/休息，换入时有短暂魂雾；收集型跟班显示三枚红心的奖励进度。
- 复制型跟班在近战武器下发射短距刃影，炸弹武器下发射余烬弹；复制光束保留追踪。所有攻击型跟班响应随从伤害增益，独立蓄力响应随从射速；友方光束不被玩家的时间停止冻结。自动射击避开钻地、无敌及墙后敌人，跟随、入场和奖励生成检查实际房间与障碍。
- 无主动道具时不存充能、不弹充能通知；真正获得充能时显示具体道具名称。收心跟班只为自己的三心奖励收集，不会隔空治疗玩家。

## 生物与环境细节

真实受伤才产生材质反馈：红心受损流血并留下地面血滴，魂心破损产生晶屑；敌人的体液、油污、金属火星、石屑、骨片、甲壳和灵体分别处理。出生使用尘土或灵光，不会让健康生物凭空流血。死亡分为倒下、凝胶摊落、碎裂和灵体上升消散，保留原生物轮廓。

环境新增 40 类细节：24 种地面装饰（苔藓、树根、碎骨、陶片、卵石、蜡痕、磨痕、排水口、水洼、碎砖、菌菇、盐粒、羽毛、旧纸、足印、蛛网、符文、湿裂缝、地衣、烟灰、锈迹、花瓣、虫卵、骨架）；八种动态氛围（薄雾、滴水、涟漪、余烬、浮尘、孢子、烟气、门口气流）；八种微型生物（苍蝇、蚂蚁、幼虫、飞蛾、甲虫、蛞蝓、蜈蚣、小蜘蛛）。不同房间使用不同组合；飞蛾靠近灯火，苍蝇追逐地面痕迹，小生物会躲避奔跑的玩家，蛞蝓留下淡痕。

墙面增加灰缝、苔垂、渗水和微动残旗，火光按粗帧变化；门闩抬升时扬尘。换房保留上一房间的短暂画面过渡和气流，新房间不会继承旧房间的粒子。地面细节按房间缓存且不参与碰撞，雾在生物与攻击预警下方绘制。出生/死亡、弹道粒子和血迹有数量上限；桌面额外粒子最多 320，触屏最多 180，地面痕迹最多 96，弹丸拖迹最多五点。

## 战斗与冒险

七层冒险与通关后的循环模式，包含宝物房、商店、首领、尖刺试炼、隐藏室和献祭交易。普通房间数量在原有基础上浮动；门口与中央路线预留通行空间。掉落、传送门及所有生物使用真实房间轮廓和障碍检测，出现异常重叠时搜索有效位置脱困。隐藏室仅向指定入口连通，避免旁邻自动接门绕过隐藏入口。

现有 22 种普通敌人与七类首领，包括新增的地窖鼠、守墓甲卫、提灯游魂与甲虫。敌人会保持距离、预判、侧闪、绕障和包抄；专属的蓄力、冲刺、逃跑、镜像与恢复动作不会再被通用追踪逻辑覆盖。首领保留各自招式并有分阶段战术、锁定目标和攻击预警。

敌人按职责分配生命：地窖鼠、环射怪偏脆，召唤者与守墓甲卫偏厚；哨兵固定站位、锁定预警方向，每轮两次三发扇射，单颗针弹伤害降为一格。甲卫蓄势时格挡正面泪弹，随后向锁定扇区盾击，背面与恢复期可以反击。环射、炮蟹的弹量和弹速降低，蜘蛛跃程收短，突进攻击增加恢复窗口。移速楼层增幅最多 25%，攻击频率增幅最多 30%，消除冷却与计时的重复加速；普通弹丸速度最多 225，首领弹丸最多 260。分裂至多两代，同房召唤总数设为 14 的上限。

共 59 件道具，其中新增八件遗物。所有遗物有独立图标，拾取、在地面等待和装备后都有反馈。装备栏可查看持有数量、用途和已组成的共鸣。

| 共鸣 | 组成 | 实际效果 |
| --- | --- | --- |
| 烬蜡誓约 | 灰烬蜡封 + 热巧克力 | 命中附加可刷新的余烬灼烧，持续命中仍会正常跳伤 |
| 铜线回路 | 旧铜线轴 + 魔术子弹 | 命中后向附近最多两个敌人传递弱化伤害，有触发冷却 |
| 镜中行列 | 背面的碎镜 + 凌云袜套 | 每三轮射击生成两枚弱化镜像弹，共享本轮伤害上限 |
| 墓园回声 | 苔藓护符 + 无舌墓铃 | 击杀使近处敌人短暂减速，效果不叠加 |
| 盐路旅人 | 粗盐布袋 + 朝圣缝线 | 低血量清房时回复一格生命，每层限一次 |

原有武器、套装及道具联动继续保留。普通弹丸、短剑、符文刃、蓄力光束与炸弹使用各自的攻击逻辑。热巧克力、短剑与硫磺的蓄力均受射速影响，角色头顶显示蓄力条；热巧克力标出追踪、穿障、穿敌的阶段。普通泪弹从面部高度发出，整段使用连续抛物线：轻微抬升后逐渐加速下坠，阴影始终落在地面，末段略微拉长并溅成小水滴。射程不随帧率变化，移动只轻微带动弹道。牛奶、巧克力、追踪、神圣等泪弹保留不同材质颜色；敌方针弹、火花和圆弹有独立轮廓。飞行过程中有短拖迹和粒子，低弹速仅在视觉上轻微横向摆动，弹速达到 280 后完全停止摆动，碰撞轨迹始终独立于摆动。

追踪改为近距吸附：按射程计算 64–180 单位的感应距离，进入目标附近后逐渐转向，保留速度并限制转弯角速度。忽略身后、钻地和隔墙的目标，并优先保持当前目标；普通泪弹、压缩桃种子/碎片、投剑及追踪光束采用相同的近距规则。

首领坠晶和抛石有独立高度、锁定落点及进度预警，高空阶段不会命中地面人物，落地只结算一次。

飞行免疫地面尖刺与火堆，实体墙石仍需绕行。放置后的炸弹可被人物、敌人和双方子弹推动，受到阻力后逐渐停下；双方普通弹丸沿运动路径统一处理生物、炸弹、墙体和射程终点，避免身后的墙石吞掉应命中的泪弹，也避免高速弹穿过挡在前方的石块。

临时房间增益与永久道具成长分开计算，强化期间拾取道具不会在换房后丢失属性。主动道具拒绝发动时保留充能；肾上腺素不再允许致死注射或同房重复扣血，满资源腰包不会空耗。怀表基础止时 3.5 秒，加成后最多 5 秒；神圣之心的受伤失效只在换房时重置。冲击巧克力的破障能力在三层解锁，与叠加上限一致；炸弹鼻祖的准星显示引爆进度并受真实房间边界约束。

## 成长上限

为避免无限叠加压垮战斗，遗物最多叠加三次，超额拾取折算为两枚金币。有效生命上限 12、灵魂心 6、基础伤害 8、普通射速 7 次/秒、移动速度 280、普通弹速 520、弹丸寿命 1.5 秒、跟随者四个。普通弹丸每轮总伤害最多 10，包含新增镜像弹。

普通敌人每 0.5 秒最多承受 22 点伤害，首领 14 点，单次伤害最多 18；特殊攻击仍有自身充能与冷却。原始道具修正保留用于组合计算，HUD 展示受上限约束后的普通属性。初始资源调整为两枚炸弹、一把钥匙、零金币；豆奶的攻速与伤害交换更温和。页面下方可展开查看上限。

## 操作

| 功能 | 按键 |
| --- | --- |
| 移动 / 射击 | WASD / 方向键 |
| 炸弹 / 领取道具、购买、献祭或交互 | E / F |
| 卡牌 / 主动道具 | Q / Space |
| 开始 / 暂停 / 重开 | Enter / P / R |

靠近道具时，画面左上角显示名称、效果和价格或献祭代价；台座道具需要 **F / 手柄 A** 领取，普通资源仍可接触拾取。

支持浏览器 Gamepad API 的标准映射手柄：左摇杆或十字键移动，右摇杆射击，A 交互，B/LB 放炸弹，X/RB 主动道具，Y 卡牌，Start 开始或暂停。摇杆有死区和模拟速度，功能键按下只触发一次；断开手柄会暂停，恢复后需先将摇杆和按键回到中立。

手机与平板自动显示横向游戏界面和触屏按键：左侧十字键移动，右侧十字键攻击，炸弹、领取、卡牌与主动道具固定在中间底部。两侧可同时长按，手指滑动支持斜向操作；抬起、取消触摸、转屏和失焦都会清理对应输入，避免松手后继续走或射击。

右上角提供“一键全屏”；支持的浏览器会请求系统全屏并锁定横向。浏览器限制全屏或横屏锁定时，页面使用横向沉浸布局适配，可把手机横持游玩。游戏区域禁用长按菜单、选字、图片拖拽和触摸滚动，保留刘海与安全区空间。生命资源显示在上方，视角和设置入口始终可达；设置中可查看行囊、图鉴、规则与调整音量，打开时自动暂停。桌面仍可手动展开屏幕键盘。失焦或切换后台会释放按键并暂停。图鉴、音量、静音和音乐开关保存在本地；存储不可用时仍可游玩。

声音使用 Web Audio：战斗音效和原创的低沉小调氛围乐在本地合成，第一次用户操作后启动。增加命中、泪弹落地、炸弹碰撞及双方脚步声；敌人脚步比玩家轻，并按距离衰减。潮石有较湿的脚步声，敌方发射和盾牌格挡有独立音效；死亡音量降低，背景和弦交叉淡化，混音加入动态压缩以减少密集战斗时的音量突增。音效有左右声像、触发间隔和并发上限。暂停时背景乐淡出；声音设置可分别关闭音乐或整体静音。

- 本轮新增 39 组生物的出生、攻击、伤势、死亡渲染检查；近距追踪的远/近/后方/墙后/钻地/射程/速度与桃弹分支；视觉摆动不改变碰撞、碎裂和拖迹上限；红心/魂心与不同材质受伤；40 类环境细节、装饰随机独立于玩法、跨房间血迹和粒子、时间停止、举物与真实换房过渡、两类立体攻击的空中与落地判定；死亡粒子完成收尾而玩法保持停止。
- 本轮以排除玩家本体伤害的 42 组「六种攻击跟班 × 七种武器」检查实际扣血；补测墙后/无敌目标筛选、友方时间停止与零时间伤害、贴身光束起点、空槽与真实充能、七形态编队保留/换入、三心奖励与拾取动画归属。另测五种手机地图可见且不遮挡按键、60×1 / 1×60 / 32×32 地图缩放及 20% 背景不透明度、39 类白色外轮廓与绘图上下文还原。
- 本轮额外验证四类蓄力的 32 组反向按键、斜向同时松键与主动改单轴、真实双指反向松开、三名镜像跟班蓄力反馈、混合输入独立释放、取消蓄力与投弹怪的实际放弹/死亡/冻结；三档画布与图标精度、本地保存和手机设置；邻接探图与密室不泄漏；另测 60 个扩大后的房间通路和 22 类躯干尺寸。
- 本环境的 14 个敌人、四名跟班、持续发射压力模拟中，桌面/触屏额外粒子分别被限制在 320/180，纹理缓存没有持续增长；该模拟不代表手机实机帧率。
- 浏览器基础回归 11 项：菜单、开始与暂停、失焦、触屏、图鉴存储、无效输入、音量、计时、楼层与循环等。
- 全部 59 件道具的三层叠加、超限拾取、主动使用、攻击及渲染；1,711 组双道具的组合重复计算与上限检查，五组新增共鸣的实际效果检查。
- 新增 59 件道具在四种临时增益下的永久属性保留与重复计算检查；59 种单件外观的像素差异与多部位叠穿检查；主动拒绝充能、祝福换房、资源拾取、30 个房间准星边界和三层冲刺解锁检查。
- 22 种普通敌人在第 1、4、7 层的 12 秒行为与弹量模拟，专属动作、哨兵固定站位、甲卫正反面受击、召唤上限检查。
- 十种房型的 40 次四向换房、15–240 FPS 起步和刹车、贴墙与绕障、七类首领和 220 个混合敌人的短时模拟。
- 120 张随机地图的连通与生成位置检查，另测 200 个房间的角色宽度可达区域、四个门口和角落；60 次墙体/障碍内实体脱困检查。
- 实际更新循环中的台座交互与献祭、飞行阻挡与陷阱免疫、炸弹三类推动和前后命中顺序、泪弹连续抛物线、落地与墙体碰撞顺序、三类蓄力攻速联动、脚步和命中声音事件。
