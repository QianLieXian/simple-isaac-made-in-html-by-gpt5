# 尘封地窖 · THE UNDERCROFT

一个单文件 Roguelite：游戏逻辑、CSS、Canvas 渲染、图标和声音全部内嵌于 `index.html`。无需构建、安装依赖或联网加载素材，下载后可在现代浏览器中直接打开，也可部署到 GitHub Pages 等静态站点。

## 画面与手感

- 斜视 2.5D 地面投影，默认 1.3 倍近景镜头，随角色平滑移动；可切换全景或全屏，画面内始终显示生命、资源与主动/卡牌状态。角色轮廓放大，低矮石块在遮住角色时半透明，碰撞仍使用统一的地面坐标。
- 障碍改为 24 单位小砖，每组最多两块，组间预留 44 单位通道；陷阱避开墙边和砖群。生成时用角色宽度检查可达区域，清除封闭小口袋。
- 门框改为有开口的石拱门，以房间颜色、专属图标和门闩区分目的地与锁定状态；隐藏门保留裂缝线索。
- 十种凸四边形房间，包括横廊、纵厅、方室、梯形厅及偏斜石廊。墙、门、地图和 HUD 用一致的房型颜色区分用途。
- 缓起步、松键收速、沿墙滑动、弹丸方向击退和按体型推挤。人物无敌期间依然受物理推动；地面材质改变牵引力。
- 粗帧步态、攻击姿态、受击闪色、四阶段尸体与溅落；59 件道具各有外观变化；靴子、衣服、披风、背包、护肩、面具、额外眼睛和头饰按部位组合，拾取时举起遗物，射击时面部与手臂反馈。武器蓄力、冲刺轨迹和特殊攻击范围分别呈现。
- 遗物置于立体底座，掉落物有厚度、漂浮和闪光；火堆、粪堆与尖刺分别绘制，高亮危险轮廓。人物、敌人、跟随者、炸弹、掉落物与双方子弹都有落地阴影。
- 做旧石板、划痕、凹坑、土粒、尘埃、虫蚁、雨丝与浮光；纹理每房间缓存，视觉随机不消耗战斗随机序列。火光、脚底阴影与暗角统一氛围。
- 页面按钮、图鉴、装备栏、音量设置、触屏键盘、调试台和弹窗采用木石、羊皮纸与暗金的复古样式。

## 战斗与冒险

七层冒险与通关后的循环模式，包含宝物房、商店、首领、尖刺试炼、隐藏室和献祭交易。普通房间数量在原有基础上浮动；门口与中央路线预留通行空间。掉落、传送门及所有生物使用真实房间轮廓和障碍检测，出现异常重叠时搜索有效位置脱困。隐藏室仅向指定入口连通，避免旁邻自动接门绕过隐藏入口。

现有 22 种普通敌人与七类首领，包括新增的地窖鼠、守墓甲卫、提灯游魂与甲虫。敌人会保持距离、预判、侧闪、绕障和包抄；专属的蓄力、冲刺、逃跑、镜像与恢复动作不会再被通用追踪逻辑覆盖。首领保留各自招式并有分阶段战术、锁定目标和攻击预警。

敌人按职责分配生命：地窖鼠、环射怪偏脆，召唤者与守墓甲卫偏厚；哨兵固定站位、锁定预警方向，每轮两次三发扇射，单颗针弹伤害降为一格。甲卫蓄势时格挡正面泪弹，随后向锁定扇区盾击，背面与恢复期可以反击。环射、炮蟹的弹量和弹速降低，蜘蛛跃程收短，突进攻击增加恢复窗口。移速楼层增幅最多 25%，攻击频率增幅最多 30%，消除冷却与计时的重复加速；普通弹丸速度最多 225，首领弹丸最多 260。分裂至多两代，同房召唤总数设为 14 的上限。

共 59 件道具，其中新增八件遗物。所有遗物有独立图标，拾取、在地面等待和装备后都有反馈。装备栏可查看持有数量、用途和已组成的共鸣。

| 共鸣 | 组成 | 实际效果 |
| --- | --- | --- |
| 烬蜡誓约 | 灰烬蜡封 + 热巧克力 | 命中附加可刷新的余烬灼烧，持续命中仍会正常跳伤 |
| 铜线回路 | 旧铜线轴 + 魔术子弹 | 命中后向附近最多两个敌人传递弱化伤害，有触发冷却 |
| 镜中行列 | 背面的碎镜 + 凌云袜套 | 每三轮射击生成两枚弱化镜像弹，共享本轮伤害上限 |
| 墓园回声 | 苔藓护符 + 无舌墓铃 | 击杀使近处敌人短暂减速，效果不叠加 |
| 盐路旅人 | 粗盐布袋 + 朝圣缝线 | 低血量清房时回复一格生命，每层限一次 |

原有武器、套装及道具联动继续保留。普通弹丸、短剑、符文刃、蓄力光束与炸弹使用各自的攻击逻辑。热巧克力、短剑与硫磺的蓄力均受射速影响，角色头顶显示蓄力条；热巧克力标出追踪、穿障、穿敌的阶段。普通泪弹从面部高度发出，整段使用连续抛物线：轻微抬升后逐渐加速下坠，阴影始终落在地面，末段略微拉长并溅成小水滴。射程不随帧率变化，移动只轻微带动弹道。牛奶、巧克力、追踪、神圣等泪弹保留不同材质颜色；敌方针弹、火花和圆弹有独立轮廓。

飞行免疫地面尖刺与火堆，实体墙石仍需绕行。放置后的炸弹可被人物、敌人和双方子弹推动，受到阻力后逐渐停下；双方普通弹丸沿运动路径统一处理生物、炸弹、墙体和射程终点，避免身后的墙石吞掉应命中的泪弹，也避免高速弹穿过挡在前方的石块。

临时房间增益与永久道具成长分开计算，强化期间拾取道具不会在换房后丢失属性。主动道具拒绝发动时保留充能；肾上腺素不再允许致死注射或同房重复扣血，满资源腰包不会空耗。怀表基础止时 3.5 秒，加成后最多 5 秒；神圣之心的受伤失效只在换房时重置。冲击巧克力的破障能力在三层解锁，与叠加上限一致；炸弹鼻祖的准星显示引爆进度并受真实房间边界约束。

## 成长上限

为避免无限叠加压垮战斗，遗物最多叠加三次，超额拾取折算为两枚金币。有效生命上限 12、灵魂心 6、基础伤害 8、普通射速 7 次/秒、移动速度 280、普通弹速 520、弹丸寿命 1.5 秒、跟随者四个。普通弹丸每轮总伤害最多 10，包含新增镜像弹。

普通敌人每 0.5 秒最多承受 22 点伤害，首领 14 点，单次伤害最多 18；特殊攻击仍有自身充能与冷却。原始道具修正保留用于组合计算，HUD 展示受上限约束后的普通属性。初始资源调整为两枚炸弹、一把钥匙、零金币；豆奶的攻速与伤害交换更温和。页面下方可展开查看上限。

## 操作

| 功能 | 按键 |
| --- | --- |
| 移动 / 射击 | WASD / 方向键 |
| 炸弹 / 领取道具、购买、献祭或交互 | E / F |
| 卡牌 / 主动道具 | Q / Space |
| 开始 / 暂停 / 重开 | Enter / P / R |

靠近道具时，画面左上角显示名称、效果和价格或献祭代价；台座道具需要 **F / 手柄 A** 领取，普通资源仍可接触拾取。

支持浏览器 Gamepad API 的标准映射手柄：左摇杆或十字键移动，右摇杆射击，A 交互，B/LB 放炸弹，X/RB 主动道具，Y 卡牌，Start 开始或暂停。摇杆有死区和模拟速度，功能键按下只触发一次；断开手柄会暂停，恢复后需先将摇杆和按键回到中立。

移动端建议横屏，开启“屏幕键盘”后支持多指移动、射击与功能键。失焦或切换后台会释放按键并暂停。图鉴、音量、静音和音乐开关保存在本地；存储不可用时仍可游玩。

声音使用 Web Audio：战斗音效和原创的低沉小调氛围乐在本地合成，第一次用户操作后启动。增加命中、泪弹落地、炸弹碰撞及双方脚步声；敌人脚步比玩家轻，并按距离衰减。潮石有较湿的脚步声，敌方发射和盾牌格挡有独立音效；死亡音量降低，背景和弦交叉淡化，混音加入动态压缩以减少密集战斗时的音量突增。音效有左右声像、触发间隔和并发上限。暂停时背景乐淡出；声音设置可分别关闭音乐或整体静音。

## 本次验证

验证工具在仓库外临时运行，游戏仍只有一个 HTML 运行文件。

- 浏览器基础回归 11 项：菜单、开始与暂停、失焦、触屏、图鉴存储、无效输入、音量、计时、楼层与循环等。
- 全部 59 件道具的三层叠加、超限拾取、主动使用、攻击及渲染；1,711 组双道具的组合重复计算与上限检查，五组新增共鸣的实际效果检查。
- 新增 59 件道具在四种临时增益下的永久属性保留与重复计算检查；59 种单件外观的像素差异与多部位叠穿检查；主动拒绝充能、祝福换房、资源拾取、30 个房间准星边界和三层冲刺解锁检查。
- 22 种普通敌人在第 1、4、7 层的 12 秒行为与弹量模拟，专属动作、哨兵固定站位、甲卫正反面受击、召唤上限检查。
- 十种房型的 40 次四向换房、15–240 FPS 起步和刹车、贴墙与绕障、七类首领和 220 个混合敌人的短时模拟。
- 120 张随机地图的连通与生成位置检查，另测 200 个房间的角色宽度可达区域、四个门口和角落；60 次墙体/障碍内实体脱困检查。
- 实际更新循环中的台座交互与献祭、飞行阻挡与陷阱免疫、炸弹三类推动和前后命中顺序、泪弹连续抛物线、落地与墙体碰撞顺序、三类蓄力攻速联动、脚步和命中声音事件。
- 通过标准手柄 API 模拟检查死区、模拟速度、持续蓄力、按键单次触发、换房和断连暂停；真实浏览器 AudioContext、离线零外部请求、桌面和手机画面检查。未使用实体手柄做硬件兼容性测试。

这些检查覆盖逻辑与短时模拟，不等同于全部多道具组合或完整七层实战的平衡结论。
